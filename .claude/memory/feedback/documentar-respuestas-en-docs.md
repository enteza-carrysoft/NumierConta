# Documentar respuestas en docs

Preferencia del usuario guardada el 2026-06-26.

Cada vez que el usuario pida un resumen, avance, desarrollo, mejora, modificacion o analisis similar, debo:

1. Responder normalmente en terminal.
2. Crear o actualizar un archivo Markdown dentro de `docs/` con el contenido entregado.

La documentacion en `docs/` forma parte del entregable, no es opcional.
